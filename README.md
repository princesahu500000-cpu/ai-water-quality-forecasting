# AI Water Quality Forecasting System (CSE276 CA1, Project P18)

Group ZJ18: Prince Sahu (12508888), Ridham Dadwal (12514189)

Water Quality Index (WQI) forecasting and decision-support app.
- Part A (real data): next-year WQI for Indian river stations.
- Part B (synthetic data): 7-day ahead WQI forecast on a generated daily dataset.

Source code: https://github.com/princesahu500000-cpu/ai-water-quality-forecasting

## Dataset
Part A uses the Kaggle dataset "Indian water quality data" (Anbarivan.N.L):
https://www.kaggle.com/datasets/anbarivan/indian-water-quality-data
The file data/water_dataX.csv (about 177 kB) is included in the submission ZIP. If it is
missing, download it from the link above and place it in the data folder.
Part B needs no download; its data is generated by src/generate_data.py.

## Setup (Python 3.13, Windows)
    py -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt

## Run everything (one command)
    python run_all.py

This runs, in order: generate_data, preprocess, eda, wqi, forecast (synthetic part), then
real_data_forecast (real part). Results are saved in report/ (tables and figures),
models/ and data/.

## Run the demo app
    streamlit run src\app.py

Open http://localhost:8501. The app has two tabs: real data (next-year forecast by state and
station) and synthetic data (7-day forecast).

## Folder structure
    src/        all Python scripts (app.py is the Streamlit demo)
    data/       datasets (raw, cleaned, WQI files)
    models/     trained models used by the app
    report/     result tables and figures
    run_all.py  runs the full pipeline

Note: the real WQI is on a 0-100 scale (higher = better); the synthetic WQI is a weighted
index (higher = worse).
